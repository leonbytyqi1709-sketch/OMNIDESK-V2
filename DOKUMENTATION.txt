1. TECHNOLOGIE-STACK
---------------------------------------------------------------------
- Frontend:   Vite 8 + React 19 + TypeScript (strict), React Router v7
- UI:         Tailwind CSS v4 (CSS-basierte Config, KEIN tailwind.config.js)
              + Shadcn/ui (Style "new-york", 20 Komponenten in
              src/components/ui), Lucide-Icons, Sonner (Toasts)
- Daten:      TanStack Query (Frontend), Drizzle ORM + Neon Serverless
              Postgres (Backend), Zod-Validierung
- Auth:       Clerk (deutsche Lokalisierung, Dark Theme)
- API:        Hono-Server unter server/ (lokal Port 8787,
              Vite-Proxy /api -> 8787). JWT-Pruefung gegen den
              oeffentlichen JWKS-Endpunkt der Clerk-Instanz
              (KEIN Clerk Secret Key noetig; Domain steckt Base64-
              kodiert im Publishable Key)
- State:      zustand (Pomodoro-Timer global, Settings persistiert)

3. ARCHITEKTUR-GRUNDSAETZE
---------------------------------------------------------------------
- Modul-Registry in src/config/modules.ts: Sidebar, Router und
  Modul-Manager speisen sich NUR aus dieser Liste. Jedes Modul wird
  per React.lazy als eigener Chunk erst beim ersten Klick geladen.
- Strikte Modultrennung: src/modules/<id>/ mit index.tsx als einzigem
  Export (+ components/, hooks/, api/). Module importieren nie
  Interna anderer Module (Ausnahme: Dashboard-Widgets duerfen die
  api/-Hooks anderer Module nutzen).
- Ein Drizzle-Schema pro Modul in src/db/schema/<modul>.ts,
  Mandantentrennung ueber user_id (Clerk-ID) mit Index.
- src/db/client.ts ist server-only (wirft im Browser, im
  tsconfig.app ausgeschlossen).
- Design-Tokens in src/styles/globals.css: Hintergrund #09090b,
  Karten #18181b, Text #fafafa, Sekundaer #a1a1aa, Signal #cf0a0a.
  Utilities: bg-gradient-accent, text-gradient-accent (Verlauf
  #230d8f -> #cf0a0a), glow, glow-strong (Neon-Schatten).
  Dark ist Standard (class="dark" auf <html>), Light-Theme vorhanden.
  Kompakt-Modus: html[data-compact='true'] setzt --spacing kleiner.
